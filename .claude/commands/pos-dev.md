# POS需求开发

你收到了一个 POS 项目(openclaw)的开发需求，请按以下流程执行：

## 项目路径
`C:\Users\haoming\IdeaProjects\gygd_pos`

## 开发流程

1. **切分支**：从 main 切出 `feature-{当前日期YYMMDD}-{需求简称}` 分支
2. **分析现有代码**：找到需求相关的已有实现，复用已有功能，对已有逻辑侵入性要小
3. **实现**：基于分析结果编码
4. **UAT自测**：连接 UAT 数据库验证
5. **合并到dev**：开发完成后合并入 dev 分支

## 输入格式

用户会给出需求描述，例如：
> 山西医保库存管理(720109):索引条件取消【业务日期】的必要性，添加【记账日期】的必要性
> 当日自动上传数据未记账数据不进行上传且可不进行界面展示
